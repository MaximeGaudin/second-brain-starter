# Build a document

Never start writing immediately.

1. list every file in the brain that touches the subject
2. show me that list and wait — I will add what is missing
3. write the outline. one line per section
4. only then write the body, citing sources as you go
5. export to PDF with my template

If a claim has no source in my files, mark it TO CHECK. Do not quietly fill the gap from general knowledge — the whole point is that this document says what I know, not what the internet knows.

Step 2 is not optional. It is the step that decides whether the document is any good.

## Style

- Information density over length. If a sentence carries nothing, cut it.
- No "Last updated" line. Version control exists.
- Never repeat content that lives in another file. Link to it instead.
