# Draft reply

Write it in the voice described in me/tone-of-voice.md. Read that file every time — it changes, and the version in your memory is out of date.

## Before writing

1. Read the whole thread, oldest message first.
2. Look up the sender in the brain. Past threads, meeting notes, anything that tells you what we already agreed.
3. Work out the one thing they are actually asking for. Most threads have exactly one.

## Then write

- Answer the question in the first line. Context after, if it is needed at all.
- Match the language of the thread.
- If the answer is no, say no in the first line, with the reason next to it.
- If a commitment is involved, name a date. Never "soon", never "next week sometime".
- If I do not have the information to answer, do not invent it. Write the reply asking for what is missing instead.

## Never

Never send. Leave it as a draft and tell me where it is.

Show me, under the draft, which files from the brain you used — so I can tell whether you actually knew what you were talking about.
