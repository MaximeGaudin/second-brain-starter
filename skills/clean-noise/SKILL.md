# Clean noise

Start with mail. Add the other sources I connected only once mail is clean.

Never delete anything. Never reply. Never accept an invitation. I approve every batch before a single message moves.

## Sort everything since the last run into three piles

1. Noise — automated, promotional, or an FYI nobody expects me to answer. Newsletters, social notifications, receipts, build and deploy status, calendar confirmations, "someone shared a document with you".
2. Worth one line — real information, but I do not need the thread. Invoices, releases, renewals, anything where I only need to know that it happened.
3. Mine — a question, a decision, a deadline, or a person waiting on me.

When you cannot tell, it goes in pile 3. Being wrong in that direction costs me nothing.

## Then

- Write pile 2 into notes/YYYY/MM/YYYY-MM-DD - inbox digest.md. One line each: sender, what it was, why it mattered, and a link back.
- Show me pile 1 and pile 2 as a numbered list, with a count per category, before you archive anything.
- Wait for me to say go, or to strike out the lines I disagree with.
- Then archive both piles in one pass, and leave pile 3 exactly where it is.

## Finish with

How many you archived, how many are left, and what is in pile 3 — five lines maximum, hardest first.

Then tell me which rule you would add to this file to make tomorrow's pass cleaner, and wait for me to approve that too.
